# Coffee Street Bar — сайт кофейни

Учебный проект по дисциплине «Фронтенд и бэкенд разработка».

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт кофейни Coffee Street Bar: меню (каталог),
страница напитка, предзаказ и адреса кофеен. Дизайн и содержимое перенесены из моего
iOS-приложения для этой же кофейни ([ccs-project](https://github.com/flapsnapdo/ccs-project)).

## Страницы сайта

| Файл | Страница | Что на ней есть |
|---|---|---|
| `index.html` | Главная | hero-блок, акции, популярные позиции с кнопкой «Заказать», бонусная программа, частые вопросы, модальное окно быстрого заказа |
| `catalog.html` | Меню | хлебные крошки, блок фильтров (категории, размер, цена), сетка из 7 карточек с бейджами |
| `product.html` | Напиток дня (Капучино) | изображение, описание, выбор размера, цена, кнопки заказа, 2 таблицы: «Размеры и цены» и «Состав и опции» |
| `order.html` | Предзаказ | форма: позиция, размер, молоко, кофейня, дата, время, контакты, комментарий, согласие |
| `contacts.html` | Кофейни | карточки кофеен со ссылкой на карту, таблица часов работы, контакты |

## Самостоятельные доработки

1. **Собственная тема и дизайн.** Сайт сделан для кофейни из моего iOS-приложения:
   цвета, логотип, скругления, «таблетки» категорий, жёлтый баннер акции и тексты
   перенесены из `AppTheme.swift` и `SampleData.swift`.
2. **Иллюстрации товаров** нарисованы в SVG в стиле иконок приложения.
3. **Карточки:** бейджи «Хит», «Новинка», «Скидка» (`position: absolute`),
   модификаторы `product-card--featured` и `product-card--discount`, старая цена,
   категория и доступные размеры.
4. **Страница товара:** выбор размера S / M / L в стиле приложения (radio + `:has()`),
   две таблицы, плашка-примечание об оплате.
5. **Меню:** фильтр категорий в виде «таблеток» (чекбоксы + `:has()`), липкая панель фильтров.
6. **Навигация:** липкая шапка, хлебные крошки на всех внутренних страницах,
   кнопка «Наверх», ссылки на разделы главной в подвале, `scroll-margin-top` у якорей.
7. **Формы:** отдельная страница предзаказа с группами полей (`fieldset`), выбор кофейни,
   даты и времени, кнопка «Очистить»; в модальном окне в заголовке показывается выбранный товар;
   общая функция проверки для двух форм; подсветка ошибочных полей и чекбокса.
8. **Новые блоки:** акции, бонусная программа, частые вопросы (`details`/`summary`), карточки кофеен.
9. **Доступность:** `aria-current="page"`, `aria-label` у навигаций, `role="status"` у сообщений,
   видимый фокус, подписи у всех полей, `alt` у изображений, контрастные цвета.
10. **SEO:** уникальные `title` и `meta description`, `sitemap.xml`, иконка сайта.

## БЭМ-структура проекта

- `site-header`, `site-nav`, `breadcrumbs`, `site-footer`, `to-top` — общие элементы страниц;
- `hero`, `section`, `promo-list`, `loyalty`, `faq` — разделы главной;
- `products-grid`, `product-card` — меню и карточки;
- `catalog-layout`, `catalog-filters`, `catalog-products`, `filters-form` — страница меню;
- `product-page`, `size-picker`, `spec-table` — страница товара;
- `order-dialog`, `order-form`, `order-page`, `success-message` — заказ;
- `shop-list`, `contact-list` — страница кофеен;
- `button` (модификаторы `button--primary`, `button--secondary`, `button--disabled`).

## CSS-архитектура

Файл `css/style.css` разделён на разделы: переменные → базовые стили → кнопка →
шапка/навигация/подвал → разделы страницы → товары и меню → модальное окно и форма.
Все цвета, отступы и скругления заданы переменными в `:root`.
